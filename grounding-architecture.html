Grounding Check Architecture

NexusAI · SemanticSimilarityChecker.check_grounding()

Inputs

Input LLM Response

The generated response text to validate. Split into individual sentences using regex: (?<=[.!?])\s+

Input Context Documents

List of RAG-retrieved passages / context chunks that the response should be grounded in.

Step 1 Batch Embedding

All texts (sentences + context docs) are sent to EmbeddingsService.embed_batch() in a single batch call for efficiency. Each text is converted into a high-dimensional vector.

Parallel Analysis

Step 2a Overall Similarity

Cosine similarity between the full response embedding and combined context embedding. Gives a high-level grounding signal.

cos(A, B) = A · B / (||A|| × ||B||)

Step 2b Sentence-Level Check

Each sentence is compared against every context document. The max similarity across all context docs is kept. If below sentence_threshold (0.5), the sentence is flagged as ungrounded.

SentenceMax SimStatus
"The API supports..."0.82✓ Grounded
"It was founded in..."0.38✗ Ungrounded
"Users can also..."0.71✓ Grounded

Step 3 Context Coverage

Measures how much of the provided context is actually used by the response. Computes cosine similarity between the response and each context doc individually, then averages. Low coverage can indicate the response ignored relevant context.

Step 4 Score Fusion

The final grounding score is a weighted blend of the overall similarity and the sentence-level grounding rate:

final_score = overall_similarity × 0.4 + sentence_grounding_rate × 0.6

Sentence-level analysis gets 60% weight because it catches fine-grained hallucinations that overall similarity might miss.

Output GroundingResult

Returns a structured result containing:

FieldTypeDescription
grounding_scorefloat 0–1Final weighted grounding score
ungrounded_sentenceslist[str]Sentences below the similarity threshold
context_coveragefloat 0–1How much context was utilized
detailsdictPer-sentence scores, counts, overall similarity

Integration Hallucination Score

Grounding feeds into the combined hallucination score with 40% weight. If grounding_score < 0.7, a low_grounding issue is raised.

hallucination_score = (1 - grounding) × 0.4 + (1 - consistency) × 0.3 + citation_issues × 0.3
