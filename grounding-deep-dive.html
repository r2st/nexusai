Sentence × Context Similarity Matrix

Step 4 (Parallel)
Overall Similarity + Context Coverage
While sentence-level checking runs, two other computations happen:

4a Overall Similarity line 148–152

The entire response is joined into one string and compared against all context docs joined into one string.

cosine_sim(full_response, " ".join(context))
= 0.74

This is a coarse "are they in the same topic?" check. It misses sentence-level hallucinations.

4b Context Coverage line 234–267

Measures how much of the provided context was actually used. Embeds the response, then computes similarity to each context doc individually and averages.

coverage = avg(0.72, 0.58, 0.31)
= 0.54

Context 3 (dashboard access) was barely used. Returned but not fed into the final grounding score — it's metadata.

⬇
Step 5
Score Fusion — Final Grounding Score
The final grounding score is a weighted average of the overall similarity and the sentence-level grounding rate (lines 202–208). Sentence-level gets 60% weight because it catches fine-grained hallucinations.
Sentence Grounding Rate
sentence_grounding_rate = grounded_count / total_sentences = 3 / 4 = 0.75
Final Grounding Score
final_score = (overall_similarity × 0.4) + (sentence_grounding_rate × 0.6)
= (0.74 × 0.4) + (0.75 × 0.6) = 0.296 + 0.45 = 0.746

Integration
How Grounding Feeds into the Hallucination Score
Back in service.py (line 416–453), the grounding score is inverted and weighted at 40% alongside consistency (30%) and citation issues (30%) to produce the final hallucination score.
Combined Hallucination Score
hallucination = (1 − grounding) × 0.4 + (1 − consistency) × 0.3 + citation_issues_norm × 0.3

If hallucination score > 0.5 → flagged as hallucination
Key insight: Sentence-level checking (60% of score) is what makes this system effective — overall similarity alone would have given S3 a free pass since the response as a whole is relevant to pricing.
