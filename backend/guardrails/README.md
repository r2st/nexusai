# NeMo Guardrails Config

Set `NEMO_GUARDRAILS_ENABLED=true` and point `NEMO_GUARDRAILS_CONFIG_PATH` to this folder (or another folder) containing a valid NeMo Guardrails configuration.

Expected files are managed by NeMo Guardrails, for example:

- `config.yml`
- `rails.co`
- optional prompt/config files

Reference: https://docs.nvidia.com/nemo/guardrails/
