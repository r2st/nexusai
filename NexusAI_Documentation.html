NexusAI Documentation

Enterprise-grade LLM-assisted Software Intelligence SaaS Platform

Project Overview

NexusAI is a comprehensive, enterprise-grade Software Intelligence platform that leverages advanced Large Language Models to provide intelligent software development insights, analysis, and automation. The platform is built with a focus on multi-tenancy, compliance, security, and seamless integration with existing development ecosystems.

Core Capabilities

Multi-LLM Support

Integrated with 8+ AI providers including Gemini, OpenAI, Anthropic, Groq, Ollama, Together AI, OpenRouter, and DeepSeek. Flexible model selection and provider abstraction.

RAG Pipeline

Advanced document ingestion, intelligent chunking, vector embeddings with pgvector, and semantic search for knowledge retrieval and context augmentation.

Hallucination Detection

Sentence-level grounding checks, consistency validation, citation tracking, and hallucination scoring to ensure AI response reliability.

Engineering Metrics

DevLake integration for DORA and SPACE metrics, enabling data-driven insights into engineering productivity and team performance.

Multi-Tenant Architecture

Complete row-level security, tenant isolation, organization management, and per-tenant configuration with PostgreSQL RLS policies.

Agent & Workflow Orchestration

Build, deploy, and manage AI agents and automated workflows with MCP (Model Context Protocol) support for external tool integration.

Compliance Ready

SOC 2, HIPAA, and GDPR compliance ready with comprehensive audit logging, data governance, and security controls.

Real-time Chat Interface

Streaming chat completions with SSE support, multi-turn conversations, message threading, and comprehensive conversation management.

Key Features

  • Multi-LLM Chat Interface: Support for 8+ AI providers with unified API abstraction and flexible model switching
  • RAG Pipeline: Document ingestion with intelligent chunking, vector embeddings (pgvector), and semantic search capabilities
  • Hallucination Detection: Advanced grounding checks at sentence level with consistency and citation validation
  • DevLake Integration: Engineering metrics including DORA metrics (deployment frequency, lead time, MTTR, change failure rate) and SPACE metrics
  • Multi-Tenant Architecture: Complete tenant isolation with Row-Level Security and per-tenant configuration
  • Agent Orchestration: AI agent management with templates, workflow builders, and MCP protocol support
  • Security & Compliance: SOC 2, HIPAA, GDPR compliance ready with comprehensive audit trails and data governance
  • Real-time Collaboration: WebSocket support for real-time updates and streaming responses
  • Cost Analytics: Per-organization, per-user, and per-model cost tracking with detailed analytics
  • Knowledge Management: Document management, collections, knowledge bases with full-text search via Meilisearch
  • External Integrations: GitHub, GitLab, Jira, Slack, and custom webhook support for seamless ecosystem integration
  • Advanced Analytics: Platform analytics, dashboards, report generation, and customizable metrics

Middleware Stack

The FastAPI backend implements a comprehensive 7-layer middleware stack for request processing, security, and observability:

1
RequestIDMiddleware
Generates unique request IDs for tracing and debugging
2
RateLimitMiddleware
Redis-backed rate limiting for API protection
3
SecurityMiddleware
CORS headers, security headers (HSTS, CSP, X-Frame-Options)
4
TenantMiddleware
Multi-tenancy context extraction and validation
5
DBSessionMiddleware
Async SQLAlchemy session lifecycle management
6
PrometheusMiddleware
Metrics collection for monitoring and observability
7
GZipMiddleware
Response compression for bandwidth optimization

Each middleware layer processes requests in order and responses in reverse order, implementing a clean separation of concerns for request handling, security enforcement, and observability.

Database Models

The NexusAI database schema consists of 13 core models with proper relationships, indexing, and Row-Level Security policies for multi-tenancy.

1. User Model

Stores user account information with organization association and profile data.

Field Type Constraints Description
id UUID PRIMARY KEY Unique user identifier
email String UNIQUE, NOT NULL User email address for login and contact
hashed_password String NOT NULL Bcrypt-hashed password (min 12 rounds)
full_name String User's full name for display
role Enum NOT NULL, DEFAULT 'member' One of: admin, manager, member, viewer
organization_id UUID FOREIGN KEY → Organization Associated organization
is_active Boolean NOT NULL, DEFAULT true Account active status
is_verified Boolean NOT NULL, DEFAULT false Email verification status
avatar_url String URL to user's avatar image
preferences JSON DEFAULT '{}' User preferences (theme, language, notifications)
last_login_at DateTime Last successful login timestamp
created_at DateTime NOT NULL Account creation timestamp
updated_at DateTime NOT NULL Last update timestamp

Complete RAG implementation with document grounding:

  • Stage 2: Chunking - Semantic document chunking with overlap
  • Stage 3: Embedding - OpenAI embeddings or local embedding models
  • Stage 4: Storage - pgvector integration for vector storage
  • Stage 5: Retrieval - Semantic similarity search with reranking
  • Stage 6: Augmentation - Context injection into prompts
hallucination/ - Hallucination Detection & Grounding

Sentence-level grounding check with confidence scoring:

hallucination_score = (1 - grounding) × 0.4 +
                            (1 - consistency) × 0.3 +
                            citation_issues × 0.3

Components:

  • Grounding verification against source documents (40% weight)
  • Internal consistency checking (30% weight)
  • Citation validation and tracking (30% weight)

Output: Flagged statements with confidence scores and remediation suggestions.

const useStreamingChat = (conversationId: string) => {
  const [streaming, setStreaming] = useState(false)
  const [streamText, setStreamText] = useState("")
  const abortControllerRef = useRef(null)

  const stream = useCallback(async (userMessage: string) => {
    setStreaming(true)
    setStreamText("")
    abortControllerRef.current = new AbortController()

    const eventSource = new EventSource(
      `/api/v1/chat/stream?conversation_id=${conversationId}&message=${userMessage}`,
      { signal: abortControllerRef.current.signal }
    )

    eventSource.onmessage = (event) => {
      const data = JSON.parse(event.data)
      setStreamText((prev) => prev + data.chunk)
    }

    eventSource.onerror = () => {
      setStreaming(false)
      eventSource.close()
    }
  }, [conversationId])

  const abort = useCallback(() => {
    abortControllerRef.current?.abort()
    setStreaming(false)
  }, [])

  return { stream, abort, streaming, streamText }
}

}

useInfiniteScroll - Pagination with Infinite Scroll

Implement infinite scroll with automatic pagination.

const useInfiniteScroll = (
  fetchFn: (page: number) => Promise,
  pageSize: number = 20
) => {
  const [items, setItems] = useState([])
  const [page, setPage] = useState(1)
  const [hasMore, setHasMore] = useState(true)
  const [isLoading, setIsLoading] = useState(false)
  const observerTarget = useRef(null)

  useEffect(() => {
    const observer = new IntersectionObserver(
      async (entries) => {
        if (entries[0].isIntersecting && hasMore && !isLoading) {
          setIsLoading(true)
          const newItems = await fetchFn(page + 1)

          if (newItems.length < pageSize) {
            setHasMore(false)
          }

          setItems((prev) => [...prev, ...newItems])
          setPage((prev) => prev + 1)
          setIsLoading(false)
        }
      },
      { threshold: 0.1 }
    )

    if (observerTarget.current) {
      observer.observe(observerTarget.current)
    }

    return () => observer.disconnect()
  }, [hasMore, isLoading, page, pageSize, fetchFn])

  return { items, observerTarget, isLoading, hasMore }
}

import axios, { AxiosInstance } from "axios"
import { useAuthStore } from "@/stores/auth"

class APIClient {
  private client: AxiosInstance
  private baseURL = "/api/v1"

  constructor() {
    this.client = axios.create({
      baseURL: this.baseURL,
      headers: {
        "Content-Type": "application/json",
      },
    })

    // Request interceptor: Add JWT token
    this.client.interceptors.request.use((config) => {
      const { token } = useAuthStore.getState()
      if (token) {
        config.headers.Authorization = `Bearer ${token}`
      }
      // Add tenant context
      const tenantId = getTenantId()
      if (tenantId) {
        config.headers["X-Tenant-ID"] = tenantId
      }
      return config
    })

    // Response interceptor: Handle 401 and refresh
    this.client.interceptors.response.use(
      (response) => response,
      async (error) => {
        if (error.response?.status === 401) {
          await useAuthStore.getState().refreshAuth()
          return this.client(error.config)
        }
        throw error
      }
    )
  }
}

Error Handling

Structured error handling with typed error responses:

interface APIError {
  status: number
  code: string
  message: string
  details?: Record
}

// Usage
try {
  await api.chat.sendMessage(conversationId, message)
} catch (error) {
  if (error instanceof APIError) {
    if (error.status === 429) {
      // Rate limited
      showToast("Too many requests. Please wait.")
    } else if (error.status === 401) {
      // Unauthorized
      logout()
    } else {
      showToast(error.message)
    }
  }
}

Retry Logic with Exponential Backoff

// Configure retry strategy
client.interceptors.response.use(null, async (error) => {
  const config = error.config
  const retryCount = (config.__retryCount || 0) + 1

  // Retry on network errors and 5xx status codes
  if (
    retryCount <= 3 &&
    (error.code === "ECONNABORTED" ||
     error.response?.status >= 500)
  ) {
    config.__retryCount = retryCount
    const delay = Math.pow(2, retryCount - 1) * 1000 // Exponential backoff
    await new Promise(resolve => setTimeout(resolve, delay))
    return client(config)
  }

  return Promise.reject(error)
})

CSRF Token Management

Cross-Site Request Forgery protection:

export const security = {
  // Get CSRF token from meta tag
  getCsrfToken: (): string => {
    return document
      .querySelector('meta[name="csrf-token"]')
      ?.getAttribute("content") || ""
  },

  // Validate CSRF token
  validateCsrfToken: (token: string): boolean => {
    const stored = security.getCsrfToken()
    return token === stored && token.length > 0
  },

  // Add CSRF to request headers
  addCsrfToHeaders: (headers: Record) => {
    const token = security.getCsrfToken()
    if (token) {
      headers["X-CSRF-Token"] = token
    }
    return headers
  }
}

import DOMPurify from "dompurify"

export const sanitizeInput = (input: string): string => {
  // Remove potentially dangerous HTML/JS
  return DOMPurify.sanitize(input, {
    ALLOWED_TAGS: ["b", "i", "em", "strong", "a"],
    ALLOWED_ATTR: ["href", "title"],
    KEEP_CONTENT: true
  })
}

export const sanitizeHtml = (html: string): string => {
  // Sanitize HTML content
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS: ["div", "p", "span", "a", "br", "code", "pre"],
    ALLOWED_ATTR: ["class", "href", "target"]
  })
}

Prompt Injection Detection

Detect and block common prompt injection patterns:

export const detectPromptInjection = (input: string): boolean => {
  const injectionPatterns = [
    /ignore previous instructions/i,
    /forget everything above/i,
    /system prompt/i,
    /you are now/i,
    /roleplay as/i,
    /pretend you are/i,
    /respond as if/i,
    /act as a/i,
    /bypass filters/i,
    /disable safety/i,
  ]

  return injectionPatterns.some(pattern =>
    pattern.test(input)
  )
}
