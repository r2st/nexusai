# Frontend

## Tech stack

- Next.js (App Router)
- React
- TanStack Query for client state/data fetching
- Tailwind utilities (via `tailwind-merge`) + Radix UI components

## Responsibilities

- Authentication UX (depending on environment setup)
- Chat UI (conversations/messages)
- Blueprint/pipeline management UI for DevLake-backed workflows
- Analytics dashboards and embedded views (as configured)

## Local development

- Frontend dev server is exposed on `http://localhost:3000`
- Backend API defaults to `http://localhost:8000/api/v1` via `NEXT_PUBLIC_API_URL`
