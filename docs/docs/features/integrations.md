# Integrations

NexusAI integrates with:

- **DevLake** for data ingestion from GitHub/Jira/CI systems and 40+ tools
- **Grafana** for dashboards (DevLake dashboards and optional monitoring Grafana)
- **Keycloak** for identity (OIDC)
- **OpenFGA** for fine-grained authorization (RBAC/ABAC-style)
- **OpenBao** for secrets management

## DevLake quick notes

- Start DevLake: `make devlake-up`
- DevLake UI: `http://localhost:4000`
- Grafana dashboards (DevLake): `http://localhost:3002`
