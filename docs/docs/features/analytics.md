# Analytics

NexusAI exposes multiple analytics surfaces:

- **Product analytics** (usage, costs, model performance)
- **Engineering analytics** (DevLake-powered metrics, DORA dashboards via Grafana)
- **AI analytics** (AI tooling usage and ROI-style reporting)

## Key backend areas

- Metrics and insights: `backend/app/services/metrics/`
- DevLake integration: `backend/app/services/devlake/`
- AI analytics: `backend/app/services/ai_analytics/`
