# Organization Management

NexusAI supports multi-tenant concepts (organizations/tenants and projects).

## Common tasks

- Create organizations/tenants
- Assign users to orgs and roles
- Manage project access

For implementation details, see the multi-tenancy and project isolation docs in the repo root `docs/` folder (and the backend models under `backend/app/models/`).
