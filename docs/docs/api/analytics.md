# Analytics API

NexusAI provides multiple analytics namespaces (usage/costs/metrics/DevLake-derived analytics).

Common entry points (non-exhaustive):

- `/analytics/*`
- `/metrics/*`
- `/ai-analytics/*`
- `/rollups/*`

Use `http://localhost:8000/docs` to explore the full set of endpoints enabled in your build.
